# Каким должен быть ответ на карточке

Карточка — не шпаргалка на полстроки, а разбор, по которому можно выучить тему с нуля и не поплыть на уточняющих вопросах. Ниже — обязательная планка.

## Объём и структура

**250–500 слов** на ответ. Меньше — недостаточно, больше — начинается вода.

Ответ делится на секции заголовками `<h4>`. Обязательны первые три, остальные — по смыслу вопроса:

```html
<h4>Коротко</h4>
<p>2–3 предложения: ровно то, что кандидат говорит первым делом. Без разгона и предысторий.</p>

<h4>Как это работает</h4>
<p>Механика по шагам, с конкретикой: что происходит, в каком порядке, кто за это отвечает.</p>

<h4>Почему так</h4>
<p>Зачем язык, браузер или библиотека сделаны именно так. Какую задачу это решает и чем платим.</p>

<h4>Подводные камни</h4>
<ul><li>Типичная ошибка и чем она проявляется.</li></ul>

<h4>Что спросят следом</h4>
<p>Один-два вероятных уточняющих вопроса и краткие ответы на них.</p>
```

## Требования к содержанию

1. **Конкретика вместо общих слов.** Не «это влияет на производительность», а «блокирует главный поток, и кадр не отрисуется, пока задача не закончится».
2. **Числа и имена там, где они есть**: пороги Core Web Vitals, версии, названия методов и флагов.
3. **Компромиссы обязательны.** У любого решения есть цена — назови её. Ответ без «зато» выглядит заученным.
4. **Код по делу.** Примеры показывают механику или контраст «неправильно/правильно», а не переписывают текст ответа.
5. **Ошибки из практики.** То, на чём реально спотыкаются: гонки запросов, потерянный контекст, утечка подписки.
6. **Никакой воды**: без «важно понимать, что», «как известно», «в современной разработке».

## Поля карточки

- `q` — вопрос в формулировке интервьюера. Не менять.
- `snippet` — **новое поле**. Код, о котором спрашивает сам вопрос («что выведет этот код»). Показывается сразу, вместе с вопросом. Без него вопрос про вывод бессмысленен.
- `a` — разбор по структуре выше.
- `code` — код, иллюстрирующий **ответ**. Показывается после раскрытия. Если код относится к вопросу, его место в `snippet`, а не здесь.
- `tip` — одна-две фразы: нюанс, который отличает сильный ответ. Обычная строка без разметки.

## Разрешённая разметка в `a`

Только `<h4> <p> <ul> <ol> <li> <code> <strong> <br>`. Никаких классов, стилей и других тегов.

## Экранирование

Внутри строк в обратных кавычках **нельзя** использовать саму обратную кавычку и последовательность `${`. В примерах кода вместо шаблонных литералов пиши конкатенацию строк: `'HTTP ' + res.status`. Если нужно показать синтаксис шаблонных литералов, экранируй: \` и \${.
